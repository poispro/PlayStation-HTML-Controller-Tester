# PlayStation-HTML-Controller-Tester
**Warning!** this whole html was (unfortunately) made by Claude.ai
This .HTML file lets you test out DualShock 3, DualShock 4, PS Move and The PS eye camera (ps3 camera)! Has simple move + ps eye orb tracking and you can set the FPS number for the ps eye (above 187! I don't recommend having 320×240 at 205fps but it kinda works up until 250fps with graphical bugs). You can test every aspect of the controllers and cameras even on Macs!

***Known issues:***
- On Macs using the PS Move wired wont register inputs from the controller.
- If you use low bandwidth ports/usb hubs and try to use e.g. 2 ps eye cameras at 640x480 it will lag heavily. Its not the softwares fault but the low bandwidth.
