PlayStation Controller + PS Eye Tester

Chrome / Edge only. Controllers use WebHID; PS Eyes use WebUSB (no driver needed, works on Mac) or driver mode. Open this file directly or from localhost, not inside a preview frame.

DualShock 3/4, DualSense, PS Move: tick several in the picker if you like. Close Steam, DS4Windows and similar apps first. Any number of PS Eyes can run at once, each with its own resolution and FPS.
